Private notes and retired order fields remain stored; they are never published as wishes. Retired order records are excluded from API payloads and cannot be changed by an ordinary travel save. Public state hides private RSVPs. Selected host identity receives logistics intentionally; do not describe this convenience mode as secure login.

Data lives in one atomic JSON store on a persistent volume. Corrupt/unwritable data fails visibly and never falls back to fabricated records. Only verified attendance enters the live roster. Legacy entries without an explicit status remain for personal review and do not count as confirmed.
